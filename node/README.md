# ginga-node

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](../LICENSE)

Node.js package and distribution for [gingaf](https://github.com/ginga-org-br/gingaf). The web application allows viewing and running NCL and HTML5 documents directly in the browser with live execution powered by the `gingaf` Web runtime and Playground. The compiled website is output to `node/playground/` and `node/gingaf/`.

## Build

To build and serve the playground locally:

```bash
make serve
```

To serve Node Express embedded player and playground:

```bash
make serve-node
```
